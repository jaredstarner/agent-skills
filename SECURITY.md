# Security policy

## Supported versions

Only `main` is supported. There are no releases.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: on the repo's **Security** tab, choose **Report a vulnerability**. Do not open a public issue.

In scope: the skills' scripts, and skill instructions that could lead an agent to leak data, run untrusted code, or take actions the user did not approve. Include what you found, how to reproduce it, and the impact you expect. Reports are acknowledged on a best-effort basis; this is a personal project with no response-time guarantee.
